# 音乐盒 1.3.0 更新说明（发布草案）

> 已随 `1.3.0` 正式版发布（2026-10-29）；兼容版本见 `mod.json` 与 README 开头的适用声明。

## 新增功能

### 非战斗界面悬浮播放器

新增圆形唱片播放器，支持在主菜单、选关、自制关卡列表/编辑界面、独立结算，以及主菜单下的商店、图鉴中显示。

- 圆形唱片可原地展开为完整播放器，不再使用分离的侧面板。
- 收起时即可上一首、播放/暂停、下一首；展开后支持选曲、调整进度与局部音量。
- 单击主体空白区域展开/收起，按住左键拖动，松开保存位置；中键、右键不操作组件。
- 可在 Mod 配置中隐藏播放器，或开启游戏内置顶；隐藏不会停止音乐，确认弹窗仍保留操作优先级。

战斗（含选卡阶段）、沙盒和加载界面隐藏播放器；未知第三方自定义场景暂不显示，避免覆盖战斗操作。

### 各界面独立选曲

新增「自制关卡界面音乐」「结算界面音乐」，与主菜单、商店、选关、图鉴分别配置。

播放器选曲和前后切歌直接保存到当前界面的 Mod 配置，返回界面或重启后仍保留；与原生配置面板共用同一份设置，不再是临时选曲。选择原版可恢复该界面的原生音乐，不改写其他界面的选曲值。

### 四种播放顺序

原“重置位置”按钮改为播放顺序选择，选择会保存：

- **顺序**：按曲库顺序播放，到末尾停止。
- **倒序**：按曲库倒序播放，到首曲结束后停止。
- **乱序**：随机播放，多首歌曲时避免连续重复同一首。
- **循环**：按列表顺序首尾衔接，持续播放。

自动切歌仅适用于已选中的本地曲目；选择原版音乐时，保持游戏原有播放方式。

## 播放与交互修复

- 修复打开普通选项/帮助弹窗、关闭后音乐意外暂停或重新开始的问题，保留用户主动暂停状态。
- 修复切场景时正常清理、重建播放器被误判为“其他功能接管”，导致播放按钮无法恢复的问题。
- 相同本地曲目在非战斗界面之间切换时恢复进度和暂停状态；不同歌曲不继承旧进度，进入战斗时清除该续播意图。
- 修复共享音乐资源导致的跨界面串曲，离开界面时还原资源与播放器缓存，避免影响战斗音乐。
- 修复选关等非主界面中播放器可见但点击被原生按钮挡住的问题，以及图鉴暂停场景树后无法操作播放器的问题。
- 修复拖动播放器时连带拖动章节轮播的问题，播放器操作与场景拖动分开处理。
- 调整播放器尺寸、按钮间距和展开布局，移除鼠标悬停提示，保留组件内状态反馈。
- 修复部分发行版裁剪运行库导致播放器初始化或左键操作报错的问题。

## 使用与范围说明

- 模组不附带音乐，继续读取存档目录下的 `Seeleyuwo/rez/BGM/`，支持子文件夹。
- 支持 WAV、OGG、MP3 及符合游戏解码条件的 FLAC；单个音频文件不超过 64 MB，格式限制沿用现有预检提示。
- 播放器的音量只作用于当前控制的背景音乐，不改变全局音乐总线，也不接管游戏音效与战斗报幕。
- 动态曲目声明仍受宿主限制：新曲目的原生配置下拉列表可能需要重启刷新，声明同步后本局可能出现“旧版本/重启应用”提示。
- 游戏内置顶不等于桌面窗口置顶；未知第三方场景和其他音乐模组的协同不能宣称完全兼容。

## 1.3.0 开发版完整记录（归档）

> 以下保留各开发版当时的原始记录，包含后来被替换的方案；不作为正式版的现行功能说明。正式更新公告只记录相对上一正式版的变化。

### v1.3.0-dev.12 · 拖动输入隔离
修复：章节轮播在早于GUI的输入阶段读取全局鼠标状态，拖动播放器也会拖动背景。操作播放器时按作用域暂停原生DragMenu输入并清除残留拖动状态，松开/离场/失焦后恢复原输入开关。
说明：不全局禁用鼠标，不修改宿主文件，组件外的场景拖动保留。

### v1.3.0-dev.11 · 切场景重绑定
修复：切场景开始后保持明确等待状态，目标场景节点就绪且宿主音乐启动后才绑定，避免提前取得随后被清理的播放器。
修复：宿主清空/重建播放器及模组自己的资源刷新不再被永久判为外部接管；来源不明的修改仍让出控制，可点击播放主动重新同步。
新增：相同本地曲目在非战斗界面切换或播放器重建后恢复进度和暂停状态；不同曲目不继承旧进度，战斗清除续播意图。

### v1.3.0-dev.10 · 播放按钮等间距
修复：上一首/播放/下一首改用原生横向容器，按钮根据实际字体最小宽度统一排列，两侧间隔均为6逻辑像素，避免硬编码坐标导致间隙不一致。

### v1.3.0-dev.9 · 非主界面点击与置顶
修复：选关/自制关卡等原生前景控件位于第10层，播放器普通层级提升以避免可见但点击被挡。图鉴暂停场景树时保留播放器输入，并区分引擎自动暂停与用户主动暂停。
新增：原生配置支持游戏内置顶，保存后即时生效，不重载音频；确认弹窗保留优先，不改变战斗场景隐藏规则。

### v1.3.0-dev.8 · 播放顺序
调整：删除重置位置按钮，替换为顺序/倒序/乱序/循环选择并保存至原生配置。
新增：自定义曲目自然结束后按所选顺序切歌；顺序和倒序到列表边界停止，乱序避免连续重复（多首时），循环首尾衔接。
说明：原版音乐继续沿用宿主播放方式；自动列表仅用于选中的本地曲目。使用独立的非循环音频资源，不改变其他场景共享资源的循环属性。

### v1.3.0-dev.7 · 非战斗场景播放器
新增：播放器支持主菜单、选关、自制关卡、结算，以及主菜单下的商店/图鉴；战斗（含选卡）、沙盒和加载时隐藏。
新增：自制关卡与结算独立音乐配置；所有播放器选曲保存到当前界面的对应配置。
调整：使用运行时生命周期托管的单一视口浮层；切场景释放音频控制但不产生重复播放器。
修复：图鉴、自制关卡、选关与结算共享音频键改为各自界面范围内替换，离开还原，避免跨场景串曲。
说明：未知第三方自定义场景默认隐藏，需明确适配，不能仅排除一个战斗场景名就宣称兼容。

### v1.3.0-dev.6 · 同场景连续播放

#### 基础维护（相对 1.2.5，本轮补记）

以下是播放器后续迭代之前的基础代码维护，归档于首个开发版，不新增开发版本号，也不将 dev.2～dev.12 的改动重复归入 dev.1。

- **宿主 API 与卸载清理**：参考游戏源码和模组模板，商店音频键在 `Initialize` 阶段通过 `context.TryRegister` 预注册，避开初始化后的注册表冻结；提前向 `context.Lifetime` 登记幂等清理。卸载取消目录/配置定时核对及更新重试，解绑场景退出事件，恢复仍由本模组持有的音频与播放器缓存，不无条件覆盖其他来源已接管的资源。
- **热重载一致性**：先准备新的曲库与选曲，再替换旧钩子；扫描或加载异常时保留原状态。重新应用已打开界面的替换，清理旧退出回调；未变化的同一音频流不再因刷新而重新起播。
- **扫描与缓存**：以完整路径、文件大小和修改时间生成曲库指纹，识别同名歌曲移动目录或文件大小变化；相同文件复用解码结果，配置选曲变化不再重扫整库。目录变化连续两次核对稳定后才加载，并在读取前后检查文件是否继续变化。
- **配置读取**：兼容旧宿主的落盘读取采用解析成功后提交的方式，校验 `version=1` 与 `modId`；解析失败不清空有效副本、不提前接受失败读取的时间戳，后续继续重试。
- **更新通知**：按公开 Updates 服务的契约在初始化主线程取得服务，异步检查上报回执；成功请求且确认没有新版时才调用 `ReportUpToDateAsync`。失败、关闭或超时不冒报“已是最新”；提交成功不等于弹窗已显示，缺少 Updates 的旧发行保留兼容适配。
- **版本比较**：数字段改为不依赖 Int32 上限的比较，修复超大主/次/补丁及预发布数字段的排序；区分预发布和构建元数据的前导零规则，允许 `1.2.3+001`，构建元数据仍不参与优先级比较。
- **日志精简**：移除逐曲注册、播放器逐项刷新、逐帧续播等常规输出；保留启动摘要、实际配置变更、目录更新及必要错误，同类异常去重，避免定时核对反复刷屏。
- **声明回写保护**：复核磁盘包版本与哈希，发现安装包被外部更新时停止回写；下拉选项比较同时检查值和目录标签，避免曲目移动后标签陈旧；对保留曲名 `off` 给出重命名提示。
- **构建闸门**：包校验改为明确断言，失败返回非零退出码；按清单中的身份与版本定位待验包，不再任取首个包。版本回归也返回失败码，并接入配置/指纹与合法包、坏包退出码测试；旧目录名称是否出现在 PDB 路径仅作诊断，不再作为错误的必过条件。

**验证与保留限制**：本轮基础维护做过两套宿主程序集的编译、SemVer 与托管逻辑回归、合法包/坏包退出码检查，不等同于完整游戏内切歌、卸载或听感验收。原生设置 API 没有公开的动态下拉选项更新入口，仍保留包内声明回写，可能使本局出现“旧版本/重启应用”提示；未宣称完全兼容其他音乐模组。
